# EUI Bank Tweaks

Small addon I made to get more control over the EllesmereUI bank grid, mainly because I wanted smaller slots in the Warband Bank without shrinking the rest of the bags UI.

## Features

- adjustable item slot size
- adjustable columns
- separate horizontal and vertical spacing
- separate bank window scale
- item text scaling
- optional Warband Bank-only mode
- built-in EUI Default, Compact, and Dense presets
- up to 10 named custom presets
- save, update, rename, and delete custom presets

## Presets

The built-in presets are **EUI Default**, **Compact**, and **Dense**.

Custom presets save the layout values only: slot size, columns, horizontal spacing, vertical spacing, bank scale, and item text scale. The Enable and Warband-only toggles stay independent.

## Control ranges

- slot size: 18-50 px
- columns: 6-30
- horizontal spacing: 0-12 px
- vertical spacing: 0-12 px
- bank scale: 50-150%
- item text scale: 50-150%

Bank scale can be adjusted in 1% steps.

## Usage

Type `/ebt` to open the settings.

Open the bank while changing the sliders to preview the layout.

## Installation

Put the `EUIBankTweaks` folder in:

`World of Warcraft\_retail_\Interface\AddOns\`

EllesmereUI Bags must be installed and enabled.

## Compatibility

EUI Bank Tweaks does not modify EllesmereUI files. It works with EllesmereUI's existing Bank and Warband Bank frames, so updating EllesmereUI will not overwrite the addon.

Version 1.1.0 was tested with EllesmereUI 9.2.9.

If EllesmereUI changes its bank internals in a future update, EUI Bank Tweaks may need an update.
