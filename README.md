# EUI Bank Tweaks

Small addon I made to get more control over the EllesmereUI bank grid, mainly because I wanted smaller slots in the Warband Bank without shrinking the rest of the bags UI.

## What it changes

- slot size
- number of columns
- spacing
- bank window scale
- item text scale
- optional Warband-only mode

There are also Compact, Dense and EUI Default buttons if you don't want to tune everything manually.

## Usage

Type `/ebt` to open the settings.

Open the bank while changing the sliders to see the layout update.

## Installation

Put the `EUIBankTweaks` folder in:

`World of Warcraft\_retail_\Interface\AddOns\`

EllesmereUI Bags must be installed and enabled.

## Compatibility

This addon doesn't edit EllesmereUI files. It changes the existing EUI bank frames after EUI lays them out.

If EllesmereUI changes its bank code in a future update, this addon may need an update too.
